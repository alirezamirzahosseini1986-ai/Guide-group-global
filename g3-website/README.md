# وب‌سایت Guide Group Global (G3)

وب‌سایت سه‌زبانه (فارسی / English / العربية) با موشن سه‌بعدی، پنل مدیریت محتوا و میزبانی رایگان روی GitHub Pages.

---

## ۱) راه‌اندازی روی GitHub (یک‌بار، حدود ۱۰ دقیقه)

1. وارد [github.com](https://github.com) شوید (یا حساب رایگان بسازید).
2. بالا سمت راست **+ ← New repository**. یک نام بگذارید (مثلاً `g3-website`)، حالت **Public** را انتخاب کنید و **Create repository** بزنید.
   > GitHub Pages برای مخزن‌های Public رایگان است.
3. در صفحه مخزن جدید روی **uploading an existing file** کلیک کنید، محتوای فایل ZIP را (پس از Extract) بکشید و رها کنید و **Commit changes** بزنید.
   - مهم: پوشه `.github` هم باید آپلود شود. اگر در ویندوز/مک دیده نمی‌شود، روش جایگزین را در بخش ۷ ببینید.
4. در مخزن به **Settings ← Pages** بروید و در قسمت **Source** گزینه **GitHub Actions** را انتخاب کنید.
5. به تب **Actions** بروید؛ ساخت سایت خودکار شروع می‌شود (حدود ۱–۲ دقیقه). پس از تیک سبز، آدرس سایت در **Settings ← Pages** نمایش داده می‌شود:
   `https://USERNAME.github.io/g3-website/`

از این به بعد هر تغییری (از پنل یا GitHub) ذخیره شود، سایت **خودکار** دوباره ساخته و منتشر می‌شود.

## ۲) دامنه اختصاصی (مثل persianguidegroup.co)

1. **Settings ← Pages ← Custom domain** را وارد کنید و Save بزنید.
2. در پنل دامنه (DNS) این رکوردها را بسازید:
   - برای دامنه اصلی: چهار رکورد `A` به `185.199.108.153`، `185.199.109.153`، `185.199.110.153`، `185.199.111.153`
   - برای `www`: رکورد `CNAME` به `USERNAME.github.io`
3. پس از فعال شدن، گزینه **Enforce HTTPS** را بزنید.
4. یک‌بار از تب Actions روی **Run workflow** بزنید تا همه لینک‌های سئو با دامنه جدید ساخته شوند.

## ۳) پنل مدیریت محتوا (تغییر متن‌ها، عکس‌ها و ویدیوها)

### روش پیشنهادی: Pages CMS (رایگان، ورود با حساب GitHub)
1. به [app.pagescms.org](https://app.pagescms.org) بروید و **Sign in with GitHub** بزنید.
2. مخزن `g3-website` را انتخاب کنید.
3. منوی سمت چپ شامل همه صفحات به هر سه زبان است: «🇮🇷 صفحه اصلی»، «🇬🇧 گلدن ویزا» و…
4. متن را تغییر دهید یا عکس/ویدیو آپلود کنید و **Save** بزنید؛ ۱–۲ دقیقه بعد روی سایت است.

### روش دوم: پنل داخل خود سایت
آدرس `https://آدرس-سایت/admin/` — ورود با **Sign In with Access Token**:
GitHub ← Settings ← Developer settings ← Personal access tokens ← **Fine-grained** ← دسترسی **Contents: Read and write** فقط برای همین مخزن.

### نکات مهم ویرایش
- هر صفحه سه نسخه دارد (فارسی، انگلیسی، عربی)؛ تغییر یک زبان را در دو زبان دیگر هم انجام دهید.
- برای هر عکس، فیلد «توضیح عکس» را پر کنید (برای گوگل و دسترس‌پذیری مهم است).
- «سئو» در بالای هر صفحه: عنوان حداکثر ~۶۰ و توضیحات ~۱۵۰ کاراکتر.
- **تنظیمات عمومی**: لوگو، تلفن، ایمیل، شبکه‌های اجتماعی، اطلاعات شرکت، کد Google Search Console و Google Analytics.

## ۴) جایگزینی لوگو، عکس‌ها و ویدیوها
- **لوگو**: تنظیمات عمومی ← برند ← لوگو (PNG یا SVG با پس‌زمینه شفاف، مناسب پس‌زمینه تیره). اگر خالی باشد، نشان طلایی G3 نمایش داده می‌شود.
- **عکس‌ها**: فعلاً از نشانی‌های سایت قدیمی Wix بارگذاری می‌شوند. پیش از حذف سایت Wix، عکس‌های نهایی را از پنل آپلود کنید.
- **ویدیوها**: فایل MP4 عمودی (۹:۱۶)، ترجیحاً زیر ۱۵ مگابایت. ویدیوی پس‌زمینه صفحه اصلی: صفحه اصلی ← هیرو ← ویدیو.

## ۵) فرم مشاوره
فرم‌ها از سرویس رایگان FormSubmit به `info@persianguidegroup.co` ارسال می‌شوند.
**اولین بار** که فرم پر شود، FormSubmit یک ایمیل تأیید می‌فرستد — روی لینک **Activate** بزنید. (ایمیل گیرنده: تنظیمات عمومی ← فرم)

## ۶) سئو بعد از انتشار
1. در [Google Search Console](https://search.google.com/search-console) سایت را اضافه کنید، کد تأیید (HTML tag) را در تنظیمات عمومی ← سئو وارد کنید.
2. آدرس `sitemap.xml` را در Search Console ثبت کنید.
3. همین کار را در [Bing Webmaster Tools](https://www.bing.com/webmasters) انجام دهید.
4. پروفایل **Google Business** برای دفتر بوداپست بسازید و به سایت لینک دهید.

## ۷) برای توسعه‌دهنده
```bash
npm install
npm start          # پیش‌نمایش محلی: http://localhost:8080
npm run build      # ساخت نهایی در پوشه _site
npm run check      # بررسی سه‌زبانه، سئو، لینک‌ها
npm run cms        # بازسازی .pages.yml پس از تغییر ساختار محتوا
```
آپلود با Git (اگر پوشه `.github` در آپلود مرورگر نیامد):
```bash
git remote add origin https://github.com/USERNAME/g3-website.git
git push -u origin main
```

### ساختار
- `src/content/{fa,en,ar}/*.json` — همه متن‌ها (پنل همین فایل‌ها را ویرایش می‌کند)
- `src/content/site.json` — تماس، شرکت، سئو
- `src/pages/` قالب صفحات · `src/assets/css/main.css` طراحی · `src/js/` موشن، کره سه‌بعدی
- فونت‌ها روی خود سایت میزبانی می‌شوند (بدون Google Fonts، مطابق GDPR).
